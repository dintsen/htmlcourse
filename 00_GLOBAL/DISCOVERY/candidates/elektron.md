# Elektron (elektron.se) — Swedish drum machines, samplers and synthesizers

Category: consumer electronics / synths. Physical product, cult brand (not a household name). Goteborg.

## Evidence
- Opened live (inspect-ref contact sheet viewed). WordPress site, 73 canvases, no WebGL, took ~19.5 s to stabilise; Neue Haas Grotesk plus the brand's own pixel screen fonts served as web fonts: Analog One, Digi One, Digi Slim, Octa One (from the machines' OLED displays; proprietary).
- Official press page https://www.elektron.se/press links Elektron-Press-Kit.zip (396 MB, https://www.elektron.se/wp-content/uploads/2026/09/Elektron-Press-Kit.zip) and an Elektron-News-Kit.zip. Extracted and counted: Machines 189 images (188 >= 1600 px), Accessories 30, Merchandise 25, Peripherals 13. Machines covered: Analog Four MKII, Analog Heat +FX, Analog Rytm MKII, Digitone II, ModelCycles, ModelSamples, Octatrack MKII, Syntakt, Tonverk.
- Hi-res examples: Octatrack MKII transparent webshop PNGs (top, back, angled; with and without shadow) up to 5760x3633; Tonverk lifestyle/feature JPGs 4800x2700; Digitone II hero 3560x2000 (machine over psychedelic artwork); Syntakt hero in neon-lit studio.
- Logos: ELEKTRON_LOGO and E-LOGO in black and white as EPS (vector) + PNG, plus Elektron_Logo_Guidelines.pdf (public brand guidelines).
- No official GLB/USDZ; no model-viewer. Video not in kit.

## Current site
Dark WordPress shop/news grid: Outbox 8 hero photo, carousels, small text, e-commerce chrome (Catalog / Shop / Kulture / Search icons). The kit's best material (colour-saturated artwork, glowing OLED pixel type, macro hands-on shots) is under-used; pixel fonts appear only in tiny details. Brand owns: black slab instruments, bold flat coloured keys, pixel display lettering, Swedish deadpan tone, rich surreal sleeve artwork (Kulture / sound packs).

## Risks
- Pixel fonts and Neue Haas are proprietary; rebuild screen type with an open pixel font or draw the glyph set procedurally.
- Press-kit usage terms not stated beyond being public press material; speculative non-commercial use.
- Knob-and-key dense machines: a rebuilt 3D model risks looking cheap; prefer multi-angle PNG plates + screen UI rendered live.
- Easy to fall into a generic black tech page; the art (colour, pixel type) must carry it.

## Hunch
The machine's own OLED is the interface: the whole site is a live pixel display with parameter rows, where hovering a product turns its knobs into page controls over Elektron's saturated sleeve artwork.
